Satellite Maritime Intelligence System

Key Features
  • Ship Detection using YOLOv8
  • Multi-class Ship Classification

  • Heatmap Generation

02 / AGRICULTURE

Crop Yield Prediction System

Problem

Estimating agricultural productivity manually is difficult because yield depends on environmental conditions and available water resources.

Solution

Built a machine learning system that predicts crop yield using environmental features and a Decision Tree Regressor. The project combines a classic Trapping Rain Water algorithm with machine learning to derive an irrigation-related feature before prediction.

Key Features
  • Crop Yield Prediction
  • Decision Tree Regression
  • Water Trapping Feature Engineering
  • Data Visualization
  • Agricultural Analytics
